# NexStay — Error Analysis & Recommended Fixes

Compiled from a static review of the HBMS, F&B/Inventory/Till/Purchases, Shared services,
and HTTP/Tenancy layers (2026-06-10). Each item lists the location, the failure scenario,
the recommended fix, and the regression/characterization test that should stay green
(or turn green) once the fix lands.

Legend: 🔴 High · 🟠 Medium · 🟡 Low

5. Everything else, roughly in severity order.
